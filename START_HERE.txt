ICCPrint 0.3 - start here
========================

PORTABLE WINDOWS PACKAGE (no Python installation needed)
1. Extract the entire ZIP to a folder you can write to.
2. Keep ICCPrint.exe and its _internal folder together.
3. Double-click ICCPrint.exe. Do not run it from inside the ZIP.
4. Add a document, select an RGB printer ICC/ICM, and inspect the preview.
5. Match the paper, ink, media and quality settings used to create the ICC.
6. Disable extra color correction in the printer driver's own properties.
7. Review preflight and print one test page before a longer job.

SOURCE CHECKOUT
Windows x64 + Python 3.12 or 3.13: run install_and_run.bat.
After setup, use run.bat. To create a portable package, run build_exe.bat.

The preview cannot validate your physical printer or driver settings.
No administrator access is required by ICCPrint itself. Printer-driver
installation may require it. This package is unsigned unless its distributor
explicitly documents signing. Never bypass a security warning automatically.
