# Security policy

ICCPrint is a local desktop printing utility and does not intentionally upload documents or ICC profiles.

If you discover a security issue, please avoid posting sensitive proof-of-concept documents, personal printer information, or private files in a public issue. Open a minimal issue describing the affected version and the class of problem, and provide only the information needed to reproduce it safely.

This project is currently maintained on a best-effort basis and does not promise a fixed response SLA.
